# ADR-0011: Design amendments from user reference boards

**Status:** Accepted (2026-07-06) — amends ADR-0010 / MASTER_PLAN PART C (see §C7)

**Context.** The user shared five reference dashboards showing his taste: glowing data on
dark canvases, node-graph pipelines, ring gauges, bold hero-color tiles, live activity
logs, rounded cards, amber heat accents.

**Decision.** Adopt into DARKPOOL:
1. **Glow discipline** — live data may glow (gradient-fade chart fills, soft bloom on
   strokes, luminous nodes/edges); static chrome never glows.
2. **Desk Pipeline Map** — the Full Desk run rendered as a live node graph (Brief →
   4 mandate nodes → divergence → CIO); gold edges = agreement, dashed dim = dissent,
   red node = risk veto. Absorbs the Consensus Constellation as its compact form.
3. **Hero tiles** — max one saturated semantic tile per view (bull-teal / bear-red flood
   with glowing area chart) for the dominant signal.
4. **Desk Tape** — streaming mono event log, entity names colored by mandate.
5. **Radius scale 12px** for cards (was 2px); hairlines + background-step elevation stay.
6. **Arc dials** (F&G with amber needle) and **sparkline watchlist tiles**.

**Rejected from references:** purple/blue neon — identity remains teal/red/gold on
obsidian; gold stays exclusive to AI judgment. Performance contract (C5) unchanged and
binding on all glow effects.
